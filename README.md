Skyline Courier — Alpine Run: a complete, original 2D canvas flight game. Fly the mail plane through a sequence of rings over a procedural alpine valley — mountains, a winding river, patchwork fields, clouds and sun — then put her down on runway 36. Throttle and turn discipline matter: fuel burns, the wing stalls, and a hard or off-centre landing ends the sortie. Two missions (Ring Run, Courier Landing), keyboard and mouse controls, synthesized engine and wind audio, and a lit instrument panel with altitude, speed, heading tape, attitude, fuel and airframe gauges.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, plain static files under `game/`.
